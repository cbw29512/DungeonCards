# Character Vault migration baseline

Character Vault v2 is layered on top of the live released pregen catalog rather than replacing it.

As of the foundation merge review, the selectable legacy catalog contains 120 records:

- Fighter / Champion, levels 1–20, both editions;
- Barbarian / Path of the Berserker, levels 1–20, both editions;
- Cleric / Life Domain, levels 1–20, both editions.

These records remain **Ready to play** under the original eleven-category gate. They become **Vault Ready** only after their advancement choices, tactics, magic-item budget, attunement state, item effects, optimization notes, and sheet-v2 presentation pass the additional Character Vault validator.
